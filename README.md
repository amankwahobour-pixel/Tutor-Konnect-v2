# TutorKonnect MVP

Connecting students and parents in Kumasi with qualified tutors.

## Tech Stack
- Frontend: Expo + React Native Web
- Backend: Node.js + Express
- Database: PostgreSQL (Supabase)
- Auth: Phone OTP (Supabase Auth)
- Payments: Paystack (Mobile Money)
- Video: Google Meet API

## Project Structure
- /frontend - Expo app
- /backend - Node.js API
- /database - SQL schema
- /docs - Documentation
- /scripts - Utilities
